二人份健康版咖哩鸡肉

2026-07-09 08:42
Comments
    Tags : 
  • food

材料,

  • 1块鸡胸肉300克切块
  • 番茄2个(可选)
  • 小洋葱2个或大洋葱1个切丝
  • 10-12朵蘑菇200克切片
  • 青椒2个切块
  • 西葫芦1根(可选)
  • 西兰花100克
  • 胡萝卜1根切丁
  • 土豆1个
  • 约10-15克咖喱粉2-3大勺
  • 姜黄粉1勺6克
  • 孜然粉1小勺3克(可选)
  • 增稠剂燕麦粉2大勺约20克用清水调成糊
  • 鸡高汤或清水400ml
  • 盐和黑胡椒适量

作法,

  • 锅中加入洋葱,蘑菇,胡萝卜,西兰花,西葫芦,土豆,咖喱粉,姜黄粉,孜然粉,鸡高汤或清水
  • 大火煮开后转小火，盖盖炖 12-15分钟，直到土豆软烂,洋葱融化,汤汁变浓,
  • 将燕麦粉冷水按1比3比例调成糊,倒入锅中搅匀,煮1分钟让汤汁变稠
  • 加少量盐提供底味
  • 下生鸡胸肉块，中火煮5分钟
  • 最后加入青椒块，搅匀即可关火余温足够加热蔬菜,加盐和黑胡椒调味

酸汤肥牛

Comments

材料,

  • 肥牛卷400克清水浸泡轻柔清洗
  • 400克金针菇切去较老根部,平刀切成0.5厘米厚的片,均匀撕开清水清洗(粉丝,黑木耳,黄瓜,绿豆芽代替金针菇也可)
  • 西红柿1个切末增加酸味(没有可以用白醋代替)
  • 姜大拇指块和蒜4片切末
  • 红泡椒10克切碎再加40克黄灯笼辣椒酱40克
  • 二荆条和小米辣各1个切圈

做法,

  • 一小锅水加盐1勺,大火烧开加金针菇焯水15秒断生后放入碗中垫底
  • 肥牛焯水变色即捞出(焯水之前沸水倒掉一些),小锅冷却后将水倒掉剩下猪油扔垃圾桶
  • 拿炒锅油六成热后放姜蒜末爆香,放辣椒酱中小火至油变黄色,加番茄炒香
  • 加400毫升水大火烧开后撇去浮沫调味,少许酱油(3克),3克料酒,5克蚝油
  • 加肥牛中小火1分钟入味后装盘
  • 放辣椒圈白芝麻蒜蓉泼上七成热滚油

材料,

  • 粉丝热水泡5分钟,软至可掐断
  • 小米辣斜切圈(不喜辣椒可以用胡萝卜粒代替)
  • 一段葱白竖着对半切开,横切眉毛葱
  • 拇指大姜切碎
  • 大蒜切丁
  • 甘蓝切粗丝洗净晾干5分钟(关键)
  • 3个鸡蛋放3分口盐搅拌(可选)

做法,

  • 油热后炒鸡蛋出锅
  • 锅内残油加少量猪油,放葱姜和一半辣椒圈,少量蒜
  • 趁锅热放甘蓝,加三分口少量盐和蚝油(蚝油也有咸味)翻炒(没有蚝油就多放味精代替)至甘蓝变绿
  • 锅中间放粉条吸汤汁15秒后加6克生抽翻炒10下,加辣椒和蒜翻炒
  • 加1小勺醋翻炒(否则菜偏甜)
  • 加鸡蛋搅拌出锅(可选)

小结,

  • 粉条是灵魂

使用imdisk在Windows10上创建ramdisk

Comments
    Tags : 
  • ramdisk
  • zh
  • 步骤 1：创建批处理脚本(CreateRamDisk.bat),
@echo off
REM 检查 R: 是否已存在（防止重复挂载）
if exist R:\ (
    echo R: already exists.
) else (
    REM 使用 ImDisk 创建 1GB 的 RAM 磁盘（动态分配内存）
    imdisk -a -t vm -s 512M -m R: -p "/fs:ntfs /q /y"

    REM 等待磁盘初始化（避免目录创建失败）
    timeout /t 2 >nul

    REM 创建 R:\temp 目录
    mkdir R:\temp 2>nul
)

关键参数说明：

-s 512M：分配 512M 物理内存（根据你的需求调整大小）。

timeout /t 2：等待 2 秒，确保磁盘初始化完成再创建目录。

  • 步骤 2：创建任务计划（taskschd.msc）

打开任务计划程序（Win + R -> taskschd.msc）。

创建基本任务：

名称：Mount ImDisk RAMDisk (Physical Memory)

触发器：当用户登录时 或 系统启动时（推荐 登录时，避免权限问题）。

操作：启动程序 -> 选择你的 CreateRamDisk.bat (C:/Windows/system32/CreateRamDisk.bat):

高级设置：

勾选 使用最高权限运行（ImDisk 需要管理员权限）。

条件：取消勾选 只有在计算机使用交流电源时才启动此任务（适用于笔记本）。

设置：可选 如果任务失败，重新启动每隔 1 分钟（确保成功挂载）。

  • 步骤 3：测试 RAMDisk

手动运行任务（右键任务 -> 运行）。

检查是否生效：

打开 文件资源管理器，确认 R: 盘存在。

检查 R:\temp 目录是否已创建。

打开 任务管理器 -> 性能 -> 内存，查看是否有相应内存占用（如 4GB）
